# سلام صدر بویز — SALAM SADR BOYS

سایت بچه‌های مدرسه‌ی سلام صدر (پایه‌های هفتم، هشتم و نهم).

## بخش‌ها
- **تکالیف** — دسته‌بندی خودکار بر اساس امروز / فردا / بعدی‌ها / گذشته‌ها (به وقت تهران)، فیلتر پایه و درس، جست‌وجو
- **درس‌ها و برنامه‌ی کلاسی** — به‌تفکیک پایه و روز
- **اعلان‌ها** — خبرهای مهم با قابلیت سنجاق
- **بخش ویژه (VIP)** — رمز‌دار؛ لینک‌ها به‌صورت رمزنگاری‌شده (AES-GCM) در فایل داده ذخیره می‌شوند
- **پنل مدیریت** — آدرس: `/panel/` (در هیچ‌جای سایت لینک نشده)

## پنل مدیریت
1. به آدرس `panel/` بروید (مثلاً `https://USERNAME.github.io/salam-sadr-boys/panel/`).
2. با رمز مدیر وارد شوید.
3. در بخش **تنظیمات**، توکن گیت‌هاب را یک‌بار وارد کنید — توکن فقط در مرورگر خودتان (localStorage) ذخیره می‌شود و **هرگز** در کد یا مخزن قرار نمی‌گیرد.
4. تغییرات را ثبت کنید و با دکمه‌ی **انتشار در سایت**، فایل `data/data.json` مستقیماً در همین مخزن به‌روز می‌شود (Data persist روی GitHub Pages).
5. دکمه‌ی **پیش‌نمایش** تغییرات را قبل از انتشار روی سایت اصلی نشان می‌دهد.

## نکات امنیتی
- رمز مدیر فقط به‌صورت هش PBKDF2-SHA256 (۱۵۰٬۰۰۰ تکرار + salt تصادفی) نگهداری می‌شود.
- محتوای VIP با AES-GCM رمزنگاری شده؛ حتی کسی که فایل داده را بخواند بدون رمز به محتوا دسترسی ندارد.
- همه‌ی ورودی‌ها قبل از نمایش escape می‌شوند (ضد XSS) و لینک‌ها sanitize می‌شوند.
- هاست استاتیک است: امنیت سمت سرور (Rate-limit واقعی، لاگ سرور) در این حالت ممکن نیست؛ برای همین توکن را فقط در دستگاه مطمئن خودتان وارد کنید و از توکن Fine-grained فقط با دسترسی همین مخزن استفاده کنید.

## ساختار
```
index.html          سایت اصلی
panel/              پنل مدیریت (لینک عمومی ندارد)
data/data.json      تمام داده‌ی سایت (با پنل به‌روز می‌شود)
assets/             فونت (وزیرمتن + لاله‌زار)، استایل، اسکریپت، نشان
```
